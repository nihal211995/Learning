Core P-Value +
Definition
Probability of observing your data (or more extreme) assuming the null hypothesis is TRUE

Not the probability that your hypothesis is correct. It only tells you how compatible your data is with H₀.

P-value = P( Data this extreme | H₀ is true )

p = 0.03 → Only 3% chance of this data if H₀ is true
p = 0.08 → 8% chance of this data if H₀ is true
p < 0.05
Reject H₀

Statistically significant. Evidence against the null.

p ≥ 0.05
Fail to Reject

Insufficient evidence. Cannot conclude an effect exists.

Error Type I Error (α) +
Definition
Rejecting H₀ when H₀ is actually TRUE — a false positive. You claim an effect exists when it doesn't.
Also called
False Positive
Significance Level
Standard value
5%

α = 0.05

When you reject H₀ using a p < 0.05 threshold, you accept at most a 5% risk of being wrong. This is the error rate you control directly through your significance threshold.

Error Type II Error (β) +
Definition
Failing to reject H₀ when H₀ is actually FALSE — a false negative. You miss a real effect that exists.
Power = 1 − β
β = 1 − Power

If Power = 0.80 → β = 0.20 (20% miss rate)
If Power = 0.90 → β = 0.10 (10% miss rate)

β is determined by your effect size and sample size. The p-value only controls Type I error — β requires separate power analysis.

Interval Confidence Interval +
Definition
A range of values likely to contain the true population parameter, at a stated confidence level

95% CI means: If you repeated this study 100 times, 95 of those confidence intervals would contain the true value.

Key relationship

If the 95% CI does not include zero (or the null value) → p < 0.05 → Reject H₀

If the 95% CI includes zero → p ≥ 0.05 → Fail to reject H₀

Power Statistical Power +
Definition
Probability of correctly rejecting H₀ when H₀ is actually FALSE. Your study's ability to detect a real effect.
Standard Power
80%

Power = 0.80

Type II Risk (β)
20%

1 − 0.80 = 0.20

Power depends on 3 things: effect size (bigger = easier to detect), sample size (larger = higher power), and α level (stricter α = lower power).
